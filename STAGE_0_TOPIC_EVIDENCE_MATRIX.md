## 2. Gap Identification & Remediation Plan

Through rigorous audit against `CURRICULUM_MASTER.md` and prior review notes, three specific curriculum gaps and one practical evaluation enhancement were identified and scheduled for immediate remediation:

1. **GPU Architecture & Throughput Computing (Roadmap Topic 2):**
   - *Audit Finding:* While CPU and memory hierarchy are deeply covered, GPU fundamentals were only briefly mentioned.
   - *Remediation:* Add a comprehensive section in `CpuArchitectureLesson.tsx` explaining CPU vs GPU design philosophies (low latency for serial single threads vs massive throughput for parallel SIMT/SIMD), GPU memory hierarchy (HBM3/GDDR6 bandwidth vs DDR5), streaming multiprocessors (SMs), warps, and when matrix multiplication benefits from parallel hardware. Add lexicon terms and update Q10 in `cpuLessonContent.ts`.

2. **Virtual Machines & Hypervisors (Roadmap Topic 4):**
   - *Audit Finding:* OS kernel, processes, threads, virtual memory, and permissions were deeply covered, but virtual machines lacked dedicated first-principles teaching.
   - *Remediation:* Add Section 16 to `OperatingSystemsLesson.tsx` teaching Type 1 (bare-metal) vs Type 2 (hosted) hypervisors, hardware-assisted CPU virtualization (Intel VT-x / AMD-V, VMX root/non-root, VMCS), and a rigorous contrast between Virtual Machines (virtualized hardware + guest kernel) and Linux Containers (shared host kernel + cgroups + namespaces). Update Q9 in `osLessonContent.ts` to test hypervisor architecture.

3. **Basic Internet Architecture & Networking Foundations (Roadmap Topic 7):**
   - *Audit Finding:* Networking basics (IP addresses, CIDR subnetting, transport ports, and the TCP 3-way handshake) were not included in any of the four Stage 0 lessons.
   - *Remediation:* Add Section 16 to `DeveloperToolingLesson.tsx` covering packet switching vs circuit switching, the 5-layer internet protocol stack, IPv4 & CIDR subnet calculations (`/24`, network ID, broadcast, usable hosts), transport layer port multiplexing (0-65535, well-known ports 80, 443, 22), the TCP 3-way handshake (SYN, SYN-ACK, ACK sequence and acknowledgment numbers), connection termination, and DNS resolution. Add pure CIDR and handshake simulation utilities in `src/utils/devTooling.ts`, python socket code example, and update Q10 in `toolingLessonContent.ts`.

4. **Milestone Project Practical Reflection & Failure Diagnosis:**
   - *Audit Finding:* The milestone project had strong unit tests, but learners needed interactive evaluation requiring explanation of journal conflict protection and manual failure diagnosis.
   - *Remediation:* Deploy an interactive Learner Self-Assessment & Reflection panel on `src/pages/Projects.tsx` with question prompts on journal conflicts, Git regression recovery, and practical command verification.
